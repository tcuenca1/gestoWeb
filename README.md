# GestoWeb

Plataforma web de reconocimiento de gestos basada en arquitectura hexagonal.

## Estructura del Proyecto
- `docs/`: Documentación del SRS y arquitectura.
- `base-datos/`: Scripts SQL de esquemas, funciones y datos iniciales.
- `backend/`: API y servicios (Arquitectura Hexagonal).
- `frontend/`: Interfaz de usuario Angular y adaptadores MediaPipe/Cámara.
